## 我们怎么用 seekdb

1. **嵌入式部署跑通**：按 README 的 30-Second Try 与 Quick Start 走通嵌入式与 server 两种启动方式，验证 MySQL 协议连接与 `CREATE TABLE` / `INSERT` / `SELECT` 基础链路。
2. **向量 + 全文混合检索**：用同一条 SQL 同时做向量相似度与全文匹配，对比“先向量再过滤”的两段式做法，记录召回与延迟差异。
3. **与 Agent/编排层结合**：把 seekdb 当作 Agent 的状态存储，验证写入/检索的可重复性（Dify 侧通过 HTTP 节点接入自建记忆服务）。
