# Contribute to seekdb

The canonical contribution workflow is maintained in the repository root [CONTRIBUTING.md](https://github.com/oceanbase/seekdb/blob/master/CONTRIBUTING.md). It covers preparing a fork, branching from `master`, building and testing, staging focused changes, and opening a pull request.

Before contributing, also review the relevant sections of this developer guide:

- [Install the toolchain](toolchain.md)
- [Build and run seekdb](build-and-run.md)
- [Write and run unit tests](unittest.md)
- [Run mysqltest](mysqltest.md)
- [Coding conventions](coding-convention.md)

Do not copy the contribution workflow into this page. Keeping a single canonical workflow prevents branch, build, and CI instructions from drifting apart.
