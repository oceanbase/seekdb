# Third-party components

This inventory describes the third-party materials collected at source revision
`8b2e34801b6024f37717630aa6182dae9b2c82ce`. Native dependency versions in the
first group are specific to `deps/init/oceanbase.el8.x86_64.deps` (el8, x86_64);
they are not asserted to be the versions used on every operating system or
architecture. Rust versions come from `Cargo.lock`, except
`seekdb-jemalloc-sys`, which comes from `deps/external/Cargo.lock`.

Paths in the **license text** column are repository-relative. The packaging
helper places these files, together with `LICENSE`, `NOTICE`, this inventory,
and `REDISTRIBUTION.md`, in the installed licenses directory. “No local patch
recorded” describes the inspected source manifests; it is not a binary diff.
See **Open items** for unresolved provenance and final-package coverage.

## Open items

- **Missing native license texts:** the pinned OpenSSL, curl, and libaio inputs
  have no corresponding file under `licenses/`; their **license text** fields
  are therefore `unspecified`. OpenSSL 1.1.1u requires both its own license and
  the original SSLeay terms. libaio's upstream 0.3.112 headers grant LGPL
  version 2 or later, while its upstream `COPYING` contains the LGPL 2.1 text.
- **libaio corresponding source and relink materials:** the exact source
  archive, any distribution-specific patches, and a verified static-relink or
  equivalent replacement kit are not staged in this change. The shared-library
  filenames are staged, but replacement has not been tested. Retaining the
  current notices alone is not represented as satisfying these obligations.
- **Unpinned legacy C components:** libev, http_parser, Snappy, and zlib have
  no exact version in the inspected manifests or `NOTICE`; their versions are
  `unspecified`. Their exact source revisions and local modification status,
  and the local modification status of both LZ4 copies and xxHash, were not
  established. The LZ4 versions are taken from the `lz4.171` and `lz4.191`
  notice labels, not from inspected upstream release archives.
- **Timezone provenance:** the public-domain notice does not identify an IANA
  release version or an SPDX license identifier, so both remain `unspecified`.
- **VSAG version correspondence:** the el8 RPM is pinned as 1.1.0, while the
  repository source archive is pinned as revision `129b82c` and records the
  native version as `129b82c-dirty`. Their exact equivalence and the
  modification state of the prebuilt el8 binary were not established.
- **Final package closure:** the engine and installation packages were not
  built or inspected. Components without a staged license text, additional
  runtime libraries introduced by platform SDKs or repair tools, and any
  package-specific revisions not represented by the cited files remain
  unspecified. This document must be checked against each final package before
  that package is represented as a complete redistribution inventory.
